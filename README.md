# ArgoCD-Blue-Green-Deployment-Strategies

## 📌 Overview
This repository is created to practice the **Blue‑Green Deployment strategy** in Kubernetes.  
It demonstrates how to run two versions of an application (Blue = current version, Green = new version) and switch traffic between them using a **LoadBalancer Service**.  
It also integrates **Argo CD** for GitOps automation, so deployments are managed directly from Git.

## 🔹 What You’ll Learn
- How Blue‑Green deployments work in Kubernetes.  
- How to expose applications using a **LoadBalancer Service**.  
- How to switch traffic between Blue and Green versions safely.  
- How to integrate **Argo CD** to automate deployments from Git.
